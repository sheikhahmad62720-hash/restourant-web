# Restaurant Web

A simple and responsive restaurant website built with **Laravel** and **Tailwind CSS**.

## Features

* Restaurant homepage
* Responsive design
* Menu section
* Modern UI
* Laravel backend

## Tech Stack

* Laravel
* PHP
* Tailwind CSS
* JavaScript
* Vite

## Installation

```bash
composer install
npm install
npm run dev
php artisan serve
```

## Description

A simple restaurant website project built to practice **Laravel and modern frontend development**.
